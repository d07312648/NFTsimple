# NFT Journey Lab 簡素化版

一般的なWebサービスに近いログインと日本円決済でNFTチケットを取得できる、研究用の静的Webプロトタイプです。従来版のUIとNFT取得後のコンテンツを維持し、NFT取得までの操作だけを簡素化しています。

## 起動方法

ZIPを解凍し、`index.html` をChrome、Edge、Safariなどで開いてください。サーバーや追加インストールは不要です。

## NFT取得までの流れ

ログインは不要です。

1. NFTチケットを選択
2. クレジットカード等（PayPay想定、その他QR決済も選択可）で日本円決済
3. パスキー（顔認証や指紋認証）を設定し、PassWalletのウォレットを作成
4. NFTチケットを取得（PassWalletへ自動追加）
5. 会場でNFTチケットを開く
6. 会場側のQRコードを読み取る
7. パスキー（顔認証や指紋認証）で認証
8. NFTチケットが使用済みになり入場

パスキー設定とウォレット作成は初回決済後のみ行います。2枚目以降は決済後にそのままNFTチケットが追加されます。秘密鍵、シードフレーズ、暗号資産、ガス代、署名などの操作は表示しません。

チケット価格は従来版の各チケットのETH価格を、研究用の基準レート「1 ETH = 542,800円」で円換算し、100円単位に丸めています。

パスキー認証、会場QRの読み取り、決済はいずれも疑似画面です。取得後のAIRDROP、5種類のミニゲーム、NFT収集、保有者特典は従来版と同じ処理を利用します。

## 研究用ログ

完了画面の「結果をJSONで保存」から、次を取得できます。

- 総所要時間
- 画面切替回数
- パスキー設定・PassWallet作成の結果
- チケット選択時刻
- 日本円の支払い方法と完了時刻
- 入力エラー回数
- 各画面の滞在時間
- 選択したチケット
- NFT自動付与の結果
- PassMarketでの出品・売却・購入・オファー・出金の記録（`marketplace`）
- 操作イベントログ

## 重要

- 実際のGoogle・LINE認証、決済、銀行振込、ブロックチェーン通信は行いません。
- 実際の請求、暗号資産、NFT、秘密鍵は生成されません。
- 認証、決済、チケット発行は、それぞれ独立した処理として実装しているため、後から実サービスへ置き換えられます。

## v5.0 PassMarket（NFTマーケットプレイス）

OpenSeaのような二次流通の仕組みを、日本円だけで体験できるマーケットプレイスを追加しました。画面上部（スマートフォンでは切替ナビ）の「マーケット」から開けます。

### 出品・売却
- PassWalletの保有NFT、またはPassMarketのマイページから「出品する」を選び、自分で日本円の価格を決めて出品
- 出品画面に「売れやすい価格帯」（相場）、フロア価格、最終取引価格、手数料の内訳、受取予定額を表示
- 価格に応じて自動で売却をシミュレーション
  - 売れやすい価格帯の中：約12〜45秒で他のユーザーが購入（安いほど早く売れる）
  - 相場より安い：約10秒以内に売れる（確認チェックが必要）
  - 相場より高い：すぐには売れず、25〜40秒後に購入希望者からオファーが届く（承諾・辞退を選択）
- 出品期間（1日・3日・7日・1か月）、価格の変更、出品の取り消しに対応。出品・価格変更・売却承認はパスキーで承認
- 公式NFTチケットは公式リセールとして定価が上限（`TICKET_RESALE_CAP_RATIO` で変更可）。使用済みチケットは記念NFTとして低い相場で取引
- 出品中のチケットは会場での入場に使用不可

### 売上・出金
- 売上は「販売価格 − マーケット手数料2.5% − クリエイター収益（コレクションごと）」が売上残高に貯まる
- 「売上・出金」ページで振込先口座（デモ口座を初期入力）を登録し、好きなタイミングで銀行口座へ出金
- 出金手数料200円、最低出金額1,000円。研究用デモでは数秒で振込完了（実サービスの目安は1〜3営業日）
- 売上残高はPassMarket・Ticket Storeでの支払いにも利用可能

### 購入・オファー
- 他のユーザーの出品を、クレジットカード・PayPay・その他のQRコード決済・売上残高で購入
- 購入したNFTはPassWalletに追加され、再び出品・売却できる（チケットは入場・ゲーム特典もそのまま利用可能）
- ウォレット未作成の場合は、決済後にパスキーを設定してPassWalletを作成
- 売上残高を使ってオファーを送信可能（出品価格の90%以上で承諾されやすい。不成立なら残高に返金）

### マーケット機能
- 探す（注目コレクション、トレンド、カテゴリ、並び替え）、ランキング、アクティビティ（他ユーザーの取引がリアルタイムに発生）、マイページ（保有・出品中・オファー・お気に入り・取引履歴）、検索、お知らせ
- コレクションページ：フロア価格・取引額・保有者数・出品数・クリエイター収益、過去30日の価格推移グラフ
- アイテムページ：価格、オファー、特性（レア度・保有率）、コントラクト等の詳細、アイテムのアクティビティ

### NFTの種類
既存の6種類のNFTチケットに加え、8つのコレクションを追加しました（ゲームは付きません）。画像ファイルは使わず、`nft-art.js` がシード値から1点ずつ異なるアートを生成します。

| コレクション | カテゴリ | 内容 |
|---|---|---|
| MOMO PIXEL FRIENDS | アバター | ピクセルアートのキャラクター |
| NEO TOKYO NIGHTS | アート | 夜の東京のジェネラティブアート |
| WAVE GENESIS | アート | 波の抽象画 |

## v5.1 ガイドと入力欄の改善

- 金額・番号の入力欄を日本語入力（全角数字・変換中の入力）に対応：出品価格、オファー金額、出金額、口座番号、カード番号（有効期限・セキュリティコードも支払い時に半角へ変換）
- マーケットを初めて開いたときに、画面の該当箇所をハイライトしながら6ステップの説明を表示（スキップ不可。最後の「はじめる」で閉じる）
  1. 二次流通：運営元が二次流通を認めている場合、NFTをマーケットプレイスで売買できること
  2. 運営への還元：公認の二次流通では運営にも手数料が入ること（従来サービスとNFTの手数料の流れの図付き）
  3. 使用後も残る価値：アート・長期特典・サインなどの付加価値があれば、使用後も売買される可能性があること
  4. NFTだからできること：所有者と取引履歴を記録し、真正性を証明できるNFTだから実現できること
  5. さまざまなジャンル：チケット以外にアート、ゲームで使えるキャラクター、観光の記念品などがあること
  6. 体験してみましょう：購入済みのチケットの売却やNFTの購入を促す
- マーケットの「探す」下部の「はじめてガイドを見る」から、いつでも再表示可能
- 購入完了ガイドの「詳細なNFTの説明を読む」の下に「閉じる」を追加
- 購入完了ガイドの表示後は、保有NFTページの「NFTの詳しい説明を読む」から、NFTの特徴と注意点（4つのポイント）をいつでも読めるように変更
- スマートフォンで別の画面からウォレットを開いた直後に購入完了ガイドが表示されると、ハイライトしたカードが画面外になる問題を修正（画面のスクロールが止まってから位置を合わせる）
- 研究用ログに、マーケットのガイド（`trade_guide_started`／`trade_guide_step_viewed`／`trade_guide_completed`）と、NFTの詳しい説明の表示（`nft_explanation_opened`／`nft_explanation_closed`）を追加。購入完了ガイドを「閉じる」で終えた場合は `nft_ownership_guide_completed` の `step` が1になる
- 「公認の二次流通で、運営にも手数料が入る」の説明と図は、購入完了ガイドからマーケットのガイド（ステップ2）へ移動

## v5.2 チュートリアル後の画面とパスキーの説明

- 最初のチュートリアル（進捗ガイド）を閉じると、チケット購入サイト（Ticket Store）へ移動するように変更（以前は何も表示されない画面になっていた）

- 研究用ログに `passkey_guide_opened`（`flow`：`ticket_store`／`passmarket`）と `passkey_guide_completed` を追加
