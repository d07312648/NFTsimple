# NFT Journey Lab 簡素化版

一般的なWebサービスに近いログインと日本円決済でNFTチケットを取得できる、研究用の静的Webプロトタイプです。従来版のUIとNFT取得後のコンテンツを維持し、NFT取得までの操作だけを簡素化しています。

## 起動方法

ZIPを解凍し、`index.html` をChrome、Edge、Safariなどで開いてください。サーバーや追加インストールは不要です。

## NFT取得までの流れ

1. GoogleまたはLINEを想定した方法で疑似ログイン
2. 5種類のNFTデジタルチケットから選択
3. クレジットカード、PayPay想定、その他QR決済から支払い方法を選択
4. チケットごとの日本円価格で疑似決済を完了後、NFTチケットをマイチケットへ自動追加
5. マイチケットから入館証を表示し、受付での入館処理を完了

ログイン時には、チケット受取用アカウントをバックグラウンドで疑似生成します。秘密鍵、シードフレーズ、暗号資産、ガス代、ネットワーク、署名などの操作はNFT取得前の画面に表示しません。

チケット価格は従来版の各チケットのETH価格を、研究用の基準レート「1 ETH = 542,800円」で円換算し、100円単位に丸めています（10の位を四捨五入）。暗号資産の価格変動や従来版で別途表示される手数料は反映しません。

Googleはアカウント選択と連携確認、LINEはQRコードまたはメールログインと連携確認を再現します。決済では、支払い方法を選んだ後にカード情報入力またはQRコード確認の画面へ進みます。いずれも入力済みの架空データを使用する疑似画面です。

取得後のAIRDROP、5種類のミニゲーム、NFT収集、保有者特典、入館証は従来版と同じ処理を利用します。

## 研究用ログ

完了画面の「結果をJSONで保存」から、次を取得できます。

- 総所要時間
- 画面切替回数
- ログイン方法
- チケット選択時刻
- 日本円の支払い方法と完了時刻
- 入力エラー回数
- 各画面の滞在時間
- 選択したチケット
- NFT自動付与の結果
- 操作イベントログ

## 重要

- 実際のGoogle・LINE認証、決済、ブロックチェーン通信は行いません。
- 実際の請求、暗号資産、NFT、秘密鍵は生成されません。
- 認証、決済、チケット発行は、それぞれ独立した処理として実装しているため、後から実サービスへ置き換えられます。
